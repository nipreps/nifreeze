    nifreeze.model.lovo module¶

    Closed-form leave-one-volume-out (LOVO) prediction for kernel models.

    A kernel predictor with fixed hyperparameters is linear in the data, and its weights depend only on the gradient table. Given the covariance \(\mathbf{A}\) of the \(N\) diffusion-weighted volumes, the prediction of volume \(i\) from all the others is (Rasmussen and Williams[1], Eq. 5.12)

    \[\hat{y}_i = -\sum_{j \neq i} \frac{P_{ij}}{P_{ii}} y_j, \quad \mathbf{P} = \mathbf{A}^{-1},\]

    so all \(N\) LOVO predictions are given by a single smoother matrix \(\mathbf{S} = \mathbf{I} - \operatorname{diag}(\mathbf{P})^{-1}\mathbf{P}\), with a zero diagonal. One inverse replaces \(N\) model fits.

    References

    [1]

    Carl Edward Rasmussen and Christopher K. I. Williams. Gaussian Processes for Machine Learning. MIT Press, Cambridge, MA, 2006. ISBN 026218253X. doi:10.7551/mitpress/3206.001.0001.

    class nifreeze.model.lovo.ClosedFormLOVOMixin(self, dataset: 'Any', *, nvox_prefit: 'int | None' = 1000, random_state: 'int | None' = 0, **kwargs: 'Any') → 'None'[source]¶

    Bases: object

    Exact leave-one-volume-out prediction from a single linear smoother.

    Subclasses implement _covariance(), which returns the (N, N) covariance of the volumes given the gradient table. The smoother is built once and rebuilt only when the gradients change. Each prediction is then one row of the smoother times the signal matrix. Because the held-out volume never contributes to its own prediction, single-fit mode returns the same genuine LOVO predictions and is not a canary.

    Hyperparameters (if any) are estimated once, on a random subsample of voxels across all volumes. This lets a handful of scalars see the held-out volume, while every prediction remains held-out.

    nifreeze.model.lovo.fit_pooled_hyperparameters(kernel: sklearn.gaussian_process.kernels.Kernel, tables: Sequence[ndarray], signals: Sequence[ndarray], alpha: float = 1e-10, maxiter: int = 200) → sklearn.gaussian_process.kernels.Kernel[source]¶

    Fit GP hyperparameters shared by several datasets (e.g., subjects).

    Maximizes \(\sum_s \log p(\mathbf{Y}_s \mid \mathbf{X}_s, \theta)\), where each dataset keeps its own gradient table \(\mathbf{X}_s\). With identical tables, this equals fitting the concatenated voxels.

    Parameters:

    • kernel (Kernel) – Kernel providing the starting values and bounds.

    • tables (Sequence of ndarray) – One design matrix per dataset, of shape (N_s, n_features).

    • signals (Sequence of ndarray) – One signal matrix per dataset, of shape (N_s, V_s).

    • alpha (float, optional) – Value added to the diagonal of each covariance (numerical jitter).

    • maxiter (int, optional) – Maximum number of L-BFGS-B iterations.

    Returns:

    A copy of kernel with the fitted hyperparameters.

    Return type:

    Kernel

    nifreeze.model.lovo.lovo_smoother(covariance: ndarray, center: bool = False) → ndarray[source]¶

    Build the closed-form leave-one-volume-out smoother from a covariance matrix.

    Parameters:

    • covariance (ndarray) – Symmetric positive-definite covariance \(\mathbf{A}\) of shape (N, N), including any noise or ridge term on its diagonal.

    • center (bool, optional) – Whether the predictor estimates a constant mean on the \(N - 1\) training volumes (as scikit-learn’s normalize_y=True does). The standard deviation of the normalization cancels in the posterior mean, so only the mean needs correcting.

    Returns:

    The smoother \(\mathbf{S}\) of shape (N, N). Row \(i\) holds the weights predicting volume \(i\) from all the others, and its diagonal is zero. With center=True, every row sums to one.

    Return type:

    ndarray

    Examples

    >>> A = np.array([[2.0, 1.0, 0.5], [1.0, 2.0, 1.0], [0.5, 1.0, 2.0]])
>>> S = lovo_smoother(A)
>>> bool(np.allclose(np.diag(S), 0.0))
True
>>> bool(np.allclose(lovo_smoother(A, center=True).sum(axis=1), 1.0))
True
